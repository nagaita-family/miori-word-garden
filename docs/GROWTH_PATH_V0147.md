# v0.14.7 Growth Path Prototype

Functional baseline remains v0.14.6 / v0.14.1 design branch.

## Goal
Make long-term progress visible without requiring final garden art.

## Garden XP
- Focus word complete: +1 XP
- Quick Review set complete: +2 XP
- Bonus Sun complete: +1 XP
- Encore 3-word set complete: +2 XP
- Ripe vegetable harvest: +1 XP
- First Weekly Challenge clear for a week: +5 XP

Hint and Peek never reduce XP.

## Visible progression
Garden screen shows:
- Garden Level and title
- XP progress bar
- next unlock / destination
- a Magic Vine path with Miori's bunny climbing toward four visible destinations

Initial destinations:
1. Little Garden
2. Flower Terrace
3. Rainbow Lookout
4. Sky Garden

Level-up events use a large overlay, sound, sparkle, and a clearly visible new level/title.

## Migration
Existing users receive a conservative one-time XP estimate from existing full loops, quick reviews, and cleared weekly challenges. No level-up popup is triggered for that initial migration.
